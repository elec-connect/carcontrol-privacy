3. Comment fonctionne l'application ?

CarControl MQTT est une application de contrôle de véhicule à distance. Elle communique avec une carte ESP8266 (équipée de relais) via le protocole MQTT.

📡 Données échangées

  • Commandes envoyées : CONTACT_ON/OFF, ESSENCE_ON/OFF, START, STOP, KLAXON, STATUS
  • Statut reçu : état des relais (contact, essence), force du signal WiFi (RSSI), uptime, état d'authentification

🔒 Ces données :

  • Circulent sur votre réseau local (WiFi domestique) ou via un broker public (ex: broker.emqx.io)
  • Ne sont jamais stockées sur nos serveurs
  • Ne sont jamais vendues, louées ou partagées avec des tiers
  • Sont effacées immédiatement après traitement

4. Permissions demandées

L'Application demande une seule permission :

  • INTERNET : Permet de communiquer avec le broker MQTT et votre véhicule

Aucune autre permission n'est requise (pas de stockage, pas de localisation, pas de caméra, pas de microphone).

5. Sécurité des données

Bien que nous ne stockions aucune donnée, nous mettons en œuvre les mesures suivantes :

  • 🔐 Authentification par mot de passe entre l'application et la carte ESP8266 (topic MQTT voiture/auth)
  • 🔒 Chiffrement recommandé : Utilisation d'un broker MQTT avec TLS (port 8883) pour sécuriser les communications
  • 🛡️ Aucune information sensible n'est affichée en clair dans l'interface
  • 📱 Pas de stockage local des identifiants de connexion

6. Services tiers
